# Post Mass Transfer Review

This repo contains a catalogue of post- mass transfer binary observations. 

- data: has the catalog
- code: is all the analysis scripts
- plots: analysis figures
- writing: tex files and pdf of corresponding paper
- 


## Cloning this repository with submodules

After cloning this repository, make sure to initialize and update submodules (such as the Overleaf writing folder) with:

```sh
git submodule update --init --recursive
```

This will ensure all necessary submodules are downloaded and available locally.
