# Raw JSON tables

Each file in this directory corresponds to a single literature source, as generated by python scripts in data_compilation
Files contain *raw, non-deduplicated* system entries in the unified
post-mass-transfer binary schema.

- Missing values are encoded as `null`
- All numeric quantities use triplets: [err-, value, err+]
- Allowed values for classification fields are documented in `data_schema.json`
- These files should not be edited by hand after generation
