Suggest a Missing Post-MT System

Two-step contribution flow for the catalog — or jump to the batch workflow to add several systems at once.

Step 1 — Check if system already exists in the catalog

Please provide a system name/ID and sky position. We check if there is a match on either the:

  • Name/ID
  • Position within 0.1 arcsec

Step 2 — Submit missing system proposal

Required minimum fields: System Name, location (RA/Dec), reference, and explanation for why it is post-MT. Format all measurements as [err-, value, err+] (fill in positive value for the - error). Note that M2 is the presumed (past) donor star, while M1 is the accretor

System Parameters

Select the single class that best matches how the system is identified in the literature. If several apply, pick the primary identification and mention the alternatives in the "Why this is post-MT" field. If nothing fits, choose "Other / propose a new class" — new classes are welcome. Full definitions are given in the accompanying paper.

What do these classes mean?
  • WUMa binary — low-mass contact binary.
  • Massive contact binary — high-mass (OB) contact binary.
  • Algol — semi-detached binary (with mass-ratio reversal), Roche-lobe-filling donor.
  • Hot subdwarf binary — core/shell He-burning low-mass stripped star (sdB/sdO) with a companion.
  • He giant — giant-like low-mass stripped helium star with a companion.
  • Intermediate-M stripped star — stripped star of roughly 1.5 to 8 Msun.
  • WR binary — Wolf-Rayet star with a (massive O-type) companion.
  • Post-AGB binary — donor recently left the AGB/RGB and is contracting towards a WD; recently terminated mass transfer.
  • EL CVn — bloated pre-He-WD stripped star with (an early-type A/F MS) companion.
  • Blue straggler binary — rejuvenated mass gainer (blue/yellow straggler), typically with a WD companion.
  • Chemically Peculiar — barium / CEMP / Li-enhanced star polluted by a former AGB donor that is now a WD.
  • Astrometric WD + MS — WD companion to MS star inferred from an astrometric orbit (e.g. Gaia).
  • Spectroscopic WD + MS — WD companion to MS star found via radial velocities / spectroscopy.
  • Self-lensing WD + MS — WD companion to MS star revealed by self-lensing brightening pulses.
  • pulsar binary — radio pulsar with a non-degenerate companion.
  • Spectroscopic compact object — detached NS/BH candidate found via radial velocities.
  • Astrometric compact object — NS/BH candidate from astrometric (Gaia) orbits.
  • high-mass XRB — accreting NS/BH with a massive donor star.

Flag any parameter above that is assumed, inferred, or not a direct dynamical measurement. Indirect (e.g. photometric or model-based) mass estimates are welcome in the M1/M2 fields — just flag them here so the catalog stays homogeneous.

Keys and units must follow the data schema format: measurements are [err-, value, err+] triplets — masses in Msun, periods in days, positions in deg — written as plain numbers with "." as decimal separator. No unit strings (write [null, 0.22, null], not "0.22 Msun").

How submission works: the button below opens a pre-filled GitHub issue in a new tab — you only need to be signed in to GitHub (no fork, no git knowledge). Check the form and press Submit new issue. Our automation then validates the JSON and converts it into a pull request, and posts the link back on your issue. The pull request awaits review by the maintainers — no further action is needed from your side.

        Prefer to do it fully programmatically?
        

          You can skip this website entirely: fork the repository, add your JSON file to
          data/proposed_additions/, and open a pull request:
        

        
# one-time: fork and clone (or use the GitHub web UI)
gh repo fork binary-observations/post_mt_catalog --clone
cd post_mt_catalog

git checkout -b proposal-YYYY-MM-DD-my-systems
cp /path/to/my_systems.json data/proposed_additions/YYYY-MM-DD_my_systems.json
git add data/proposed_additions/
git commit -m "Propose missing post-MT systems"
git push origin HEAD
# then open a pull request on GitHub
